## Overview

A high-performance, visually stunning personal portfolio website built with Svelte 5 and SvelteKit. This project demonstrates modern web development practices with a focus on performance, accessibility, and internationalization.

## Key Features

- **Modern Framework**: Built with Svelte 5, leveraging the latest features and runes for optimal performance
- **Responsive Design**: Developed using Tailwind CSS v4 for a fluid, mobile-first user interface
- **Multi-language Support**: Integrated i18n with Paraglide-js supporting English and Indonesian
- **Content Management**: MDSveX integration for markdown-based articles and blog posts
- **Testing Suite**: Comprehensive testing with Vitest for unit tests and Playwright for E2E tests
- **Type Safety**: Full TypeScript implementation for robust code quality

## Technical Highlights

The project showcases modern web development best practices including:
- Component-based architecture with Svelte 5
- Utility-first CSS with Tailwind CSS v4
- Static site generation for optimal performance
- Automated testing for reliability
- Internationalization for global reach

## Development Tools

- Svelte 5 with latest runes and reactive features
- SvelteKit for routing and server-side rendering
- Tailwind CSS v4 for styling
- MDSveX for markdown content
- Paraglide-js for internationalization
- Vitest and Playwright for comprehensive testing

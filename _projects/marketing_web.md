## Overview

Zenin Agency is a high-performance marketing and agency landing page designed with strong visual storytelling, scroll reveal animations, and a focus on conversion. Built with modern web technologies for optimal performance and user experience.

## Key Features

- **Visual Storytelling**: Engaging scroll reveal animations and transitions that capture visitor attention
- **Conversion-Focused Design**: Strategic layout and call-to-action placement for maximum engagement
- **Modern Tech Stack**: Built with SvelteKit 2 and Svelte 5 for exceptional performance
- **Responsive Layout**: Tailwind CSS 4 ensures perfect display across all devices
- **Multi-language Support**: Paraglide JS integration supporting English and Indonesian markets
- **Quality Assurance**: Comprehensive testing with Vitest and Playwright

## Technical Implementation

The landing page leverages cutting-edge web technologies:
- **Framework**: SvelteKit 2 with Svelte 5 for reactive UI
- **Styling**: Tailwind CSS 4 for modern, utility-first design
- **Internationalization**: Paraglide JS for seamless multi-language support
- **Testing**: Vitest for unit/component tests and Playwright for E2E testing
- **Type Safety**: TypeScript for robust code quality

## Development Highlights

- Optimized for performance with lazy loading and code splitting
- SEO-friendly with server-side rendering capabilities
- Fully tested with automated unit and E2E tests
- Internationalized content management
- Mobile-first responsive design approach

## Business Value

This project demonstrates expertise in creating high-converting marketing websites with:
- Strong visual impact through animations
- Cross-browser compatibility
- Multi-language support for global reach
- Performance optimization for better user experience
